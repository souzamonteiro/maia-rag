# Roadmap

## v0.1 — Autonomous Local RAG
Web/CLI/watcher ingestion, AI classification, Qdrant, SQLite, PDF/DOCX/text/code baseline, vector retrieval and citations.

## v0.2 — Knowledge Management
Collections, provenance-aware metadata editing, background job queue/progress, document deletion/reprocessing, better PDF/Markdown parsing, Tree-sitter code chunking.

## v0.3 — Retrieval Quality
Hybrid vector + lexical retrieval, fusion, reranking, context budgeting, retrieval evaluation suite.

## v0.4 — Production Operations
PostgreSQL, auth/ACL, audit log, metrics, backup/restore, quotas and multi-worker processing.

## v0.5 — Maia Knowledge Fabric
Code graph, repository ingestion, OCR/tables, version lineage and richer integrations with Maia Chat, Maia Studio and MaiaScript `@prompt` workflows.
